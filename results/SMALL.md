# Small-server results

> Generated by `tools/small-report.mjs` from the runs in [`raw/small/`](raw/small/). [Methodology §13](../METHODOLOGY.md#13-the-small-server-rig) says how a campaign runs.

Each campaign runs every self-hosted target alone on one small server, with its own PostgreSQL beside it, the way someone renting the smallest plan would run it. The server reboots before every run. k6 runs on a second machine and offers each read scenario at rising rates. Every figure is the median of the campaign's runs, with the lowest and highest beneath it and the number of runs. These figures never enter the head-to-head in [RESULTS.md](RESULTS.md), which runs every target on one larger machine.
